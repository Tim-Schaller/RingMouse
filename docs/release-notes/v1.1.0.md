### New

- **Import from Logi Options+:** takes over the Actions Ring with its folders, the button assignments and the app
  profiles of an installed Options+ – in the first-run setup or under Settings → General. A preview shows what is taken
  over and what not (e.g. actions of the Excel or Teams plugins); you choose the parts.
- **Export and import** of the RingMouse configuration (e.g. for another computer), including Actions Ring presets
  exported from Options+ (`.lp5`). A backup is created before every import.
- `RingMouse.exe --import-report <file>` shows what an Options+ import would produce, without changing anything.

### Downloads

| File | What it is |
|---|---|
| `RingMouse.exe` | The app – a single self-contained file, no installation and no .NET needed |
| `RingMouse-uiAccess.zip` | Optional variant that may also operate windows running with admin rights (see the README) |
| `ringmouse-probe.exe` | Diagnostic tool for bug reports |
| `SHA256SUMS.txt` | SHA-256 checksums of all files |

Updating: quit RingMouse (tray → Exit), replace `RingMouse.exe`, start it again. The exe is not code-signed, so Windows
SmartScreen may warn on the first start: *More info* → *Run anyway*.

**Deutsch:** Neu ist der **Import aus Logi Options+** (Actions Ring samt Ordnern, Tastenbelegungen und App-Profile – in der
Ersteinrichtung oder unter Einstellungen → Allgemein) sowie **Export und Import** der RingMouse-Konfiguration, auch von
aus Options+ exportierten Ring-Presets (`.lp5`). Vor jedem Import wird eine Sicherung angelegt. Details im
[deutschen README](https://github.com/Tim-Schaller/RingMouse/blob/main/README.de.md#import--export).
