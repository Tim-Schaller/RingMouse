First public release of RingMouse – a lightweight replacement for Logi Options+ on Windows: Actions Ring on a mouse
button, battery level in the tray, DPI, button assignments and per-app profiles for Logitech mice. No telemetry, no
network access. English and German user interface.

### Downloads

| File | What it is |
|---|---|
| `RingMouse.exe` | The app – a single self-contained file, no installation and no .NET needed |
| `RingMouse-uiAccess.zip` | Optional variant that may also operate windows running with admin rights (see the README) |
| `ringmouse-probe.exe` | Diagnostic tool for bug reports |
| `SHA256SUMS.txt` | SHA-256 checksums of all files |

### Getting started

1. Copy `RingMouse.exe` to a permanent folder, e.g. `%LOCALAPPDATA%\Programs\RingMouse\`, and start it.
2. Quit Logi Options+ (it fights over the same buttons).
3. When your mouse is connected, press the button that should open the Actions Ring – done.

The exe is not code-signed, so Windows SmartScreen may warn on the first start: *More info* → *Run anyway*.

Tested with the MX Vertical over Bluetooth. Other Logitech mice with HID++ 2.0 (Bluetooth, Bolt, Unifying, cable) should
work – please report your results in an issue.
