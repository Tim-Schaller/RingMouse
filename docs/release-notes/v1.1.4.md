### Fixes

- **Autostart no longer breaks silently when the exe is moved.** Until now, a Run entry or scheduled task kept pointing
  to the old place, and RingMouse simply did not start any more. Now RingMouse checks on every start where its autostart
  points:
  - a Run entry pointing to a file that no longer exists is repointed to the running exe automatically;
  - a scheduled task can only be re-created via UAC – until you do that, RingMouse adds a Run entry so it still starts
    with Windows, and a notification tells you how to restore the task (Settings → General → **Set up autostart now**);
  - an autostart that starts another existing copy of RingMouse is left alone.

  Settings → General now also shows where the autostart points and warns if that file is gone.
- **"Set up autostart now" with the scheduled task works again.** Since v1.1.2, RingMouse checks the newly created task
  before keeping it, but could not read it back (`schtasks` returns its XML in the console code page, not UTF-16). The
  task was then deleted again and the settings reported *"Could not create the scheduled task (UAC cancelled?)"*.
  RingMouse now reads the task through the Windows Task Scheduler API, exactly and including special characters in
  user names.

### New

- **Start menu entry:** RingMouse adds a *RingMouse* shortcut to your Start menu (per user, no admin rights), so you can
  always start it by hand – if it is already running, this opens the settings. The shortcut is repaired the same way
  after a move and can be turned off under Settings → General.

### Downloads

| File | What it is |
|---|---|
| `RingMouse.exe` | The app – a single self-contained file, no installation and no .NET needed |
| `RingMouse-uiAccess.zip` | Optional variant that may also operate windows running with admin rights (see the README) |
| `ringmouse-probe.exe` | Diagnostic tool for bug reports |
| `SHA256SUMS.txt` | SHA-256 checksums of all files |

From v1.1.3 on, RingMouse installs this update by itself. Updating by hand: quit RingMouse (tray → Exit), replace
`RingMouse.exe`, start it again. The exe is not code-signed, so Windows SmartScreen may warn on the first start:
*More info* → *Run anyway*. Verify your download against `SHA256SUMS.txt`.

**Deutsch:** Der Autostart geht nicht mehr still kaputt, wenn die Exe verschoben wird. RingMouse prüft bei jedem Start,
wohin sein Autostart zeigt: Ein Run-Eintrag auf eine nicht mehr vorhandene Datei wird automatisch umgebogen. Eine
Aufgabe lässt sich nur per UAC neu anlegen – bis dahin startet RingMouse über einen Run-Eintrag, und eine Meldung erklärt,
wie die Aufgabe wiederhergestellt wird (Einstellungen → Allgemein → **Autostart jetzt einrichten**). Ein Autostart auf
eine andere vorhandene Kopie bleibt unangetastet; die Einstellungen zeigen jetzt, wohin der Autostart zeigt. Außerdem
funktioniert **„Autostart jetzt einrichten“ als Aufgabe wieder** – seit v1.1.2 konnte RingMouse die neue Aufgabe nicht
zurücklesen (schtasks liefert die XML in der Konsolen-Codepage) und hat sie wieder gelöscht. **Neu:**
RingMouse trägt sich ins Startmenü ein (ohne Adminrechte), damit es sich jederzeit von Hand starten lässt; läuft es schon,
öffnen sich die Einstellungen. Der Eintrag wird nach einem Umzug ebenso repariert und lässt sich abschalten.
