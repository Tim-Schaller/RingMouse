### New: automatic updates

RingMouse can now **keep itself up to date**. It checks GitHub for a new signed release a few minutes after start
and every 12 hours, downloads it and installs it once the PC has been idle for a few minutes. You can turn this off or
trigger it manually under **Settings → General → Updates**.

- **Signed and safe:** every release ships a signed `latest.json`; RingMouse only installs an update whose signature
  matches its built-in key and whose version is newer. Taking over the download source or the GitHub account is not
  enough to push foreign code.
- **Only network connection:** the update check is the single connection RingMouse makes – no telemetry, no account.
  See [SECURITY.md](https://github.com/Tim-Schaller/RingMouse/blob/main/SECURITY.md).
- **uiAccess variant:** updates itself only with a notification (it lives in a protected folder and is locally
  signed) – update it manually and re-run `install-uiaccess.ps1`.

> This is the **last update you have to install by hand**. From v1.1.3 on, RingMouse updates itself (unless you turn
> it off).

### Downloads

| File | What it is |
|---|---|
| `RingMouse.exe` | The app – a single self-contained file, no installation and no .NET needed |
| `RingMouse-uiAccess.zip` | Optional variant that may also operate windows running with admin rights (see the README) |
| `ringmouse-probe.exe` | Diagnostic tool for bug reports |
| `SHA256SUMS.txt` | SHA-256 checksums of all files |

Updating: quit RingMouse (tray → Exit), replace `RingMouse.exe`, start it again. The exe is not code-signed, so Windows
SmartScreen may warn on the first start: *More info* → *Run anyway*. Verify your download against `SHA256SUMS.txt`.

---

**Deutsch:** RingMouse **aktualisiert sich ab jetzt selbst** – es prüft GitHub auf ein neues, signiertes Release, lädt
es und installiert es, sobald der PC eine Weile unbenutzt ist (unter Einstellungen → Allgemein → Updates abschaltbar
oder manuell auslösbar). Installiert wird nur, was mit dem eingebauten Schlüssel signiert ist und neuer ist – die
Übernahme der Download-Quelle oder des GitHub-Kontos genügt also nicht für Fremdcode. Die Update-Prüfung ist die
einzige Netzwerkverbindung. Die uiAccess-Variante meldet nur und wird manuell aktualisiert. **Dies ist das letzte
Update, das du von Hand einspielen musst.**
