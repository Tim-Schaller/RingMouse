### Fixes

- **RingMouse no longer stays half-started when the taskbar is not ready yet at sign-in.** If Windows could not add the
  tray icon right away (*"TryCreate failed"*), the start stopped at that point: RingMouse kept running, but never looked
  for the mouse. Settings showed *"No Logitech HID++ device found"*, **Reconnect** did nothing, and starting RingMouse
  again from the Start menu had no effect because the half-started instance was still running. Now:
  - the tray icon is retried (every 2 s for a minute, then every 15 s) while everything else starts normally – ring,
    buttons and battery work even before the icon appears;
  - notifications from that time (e.g. *config.json is invalid*) are shown as soon as the icon is there;
  - should the start ever fail for another reason, RingMouse exits cleanly and tries again once after 15 seconds instead
    of staying in the background without function.

### Downloads

| File | What it is |
|---|---|
| `RingMouse.exe` | The app – a single self-contained file, no installation and no .NET needed |
| `RingMouse-uiAccess.zip` | Optional variant that may also operate windows running with admin rights (see the README) |
| `ringmouse-probe.exe` | Diagnostic tool for bug reports |
| `SHA256SUMS.txt` | SHA-256 checksums of all files |

From v1.1.3 on, RingMouse installs this update by itself. Updating by hand: quit RingMouse (tray → Exit), replace
`RingMouse.exe`, start it again. The exe is not code-signed, so Windows SmartScreen may warn on the first start:
*More info* → *Run anyway*. Verify your download against `SHA256SUMS.txt`.

**Deutsch:** RingMouse bleibt nicht mehr halb gestartet hängen, wenn die Taskleiste bei der Anmeldung noch nicht bereit
ist. Konnte Windows das Tray-Symbol nicht sofort anlegen („TryCreate failed“), brach der Start an dieser Stelle ab:
RingMouse lief weiter, suchte aber nie nach der Maus – die Einstellungen zeigten „Kein Logitech-HID++-Gerät gefunden“,
**Neu verbinden** wirkte nicht, und ein erneuter Start aus dem Startmenü blieb wirkungslos. Jetzt wird das Tray-Symbol
wiederholt angelegt (eine Minute lang alle 2 s, danach alle 15 s), während alles andere normal startet – Ring, Tasten und
Akku funktionieren schon vorher. Hinweise aus dieser Zeit erscheinen, sobald das Symbol da ist. Scheitert der Start doch
einmal aus einem anderen Grund, beendet sich RingMouse sauber und versucht es nach 15 Sekunden genau einmal erneut.
